# Backstep demo video

A 57 second demo of Backstep, built entirely in code with [Remotion](https://www.remotion.dev/). No screen recording. Every terminal, table and diagram is a React component.

```sh
npm install
npm run studio   # preview and scrub in the browser
npm run render   # out/backstep-demo.mp4
npm run poster   # out/poster.png
```

All on screen copy and data lives in `src/data.ts`, with comments pointing at the source file each value came from.
